# Apple materials guidance for the dashboard

Source: [Apple Human Interface Guidelines: Materials](https://developer.apple.com/design/human-interface-guidelines/materials), consulted 2026-11-08.

These are application notes, not an Apple-authored specification.

- Use glass to distinguish navigation and interactive controls from data.
- Keep charts and numeric measurements on solid, readable surfaces.
- Apply the effect sparingly and maintain contrast as backgrounds change.
- Supply opaque fallbacks and respect reduced-transparency preferences.
- A browser CSS treatment is an interpretation, not the native Apple material.

The official page was downloaded to `/tmp/hazmat-apple-materials.html` for reference.
